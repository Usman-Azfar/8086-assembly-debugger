8086 Assembly Debugger

A DEBUG.COM-style debugger written from scratch in pure 8086 assembly, running live in your browser.

Source code on GitHub How it works

The real program runs inside DOSBox compiled to WebAssembly (js-dos). Click the screen, then type commands and press Enter. A physical keyboard works best.

Things to try

Letters can be upper or lower case, and numbers are hexadecimal.

  1. r shows the registers, the flags and the next instruction.
  2. u disassembles the demo program loaded at 0100.
  3. t executes one real instruction. Repeat it and watch the flags change: OV NG appear after ADD AX,0001.
  4. t 10 runs the rest of the demo. Then d 200 l 10 shows the value it stored in memory.
  5. e 300 'Hello' 0d 0a 24 writes a string, and d 300 l 10 shows it.
  6. r f, then cy zr, sets the carry and zero flags.
  7. h 1234 0fff adds and subtracts in hex.
  8. ? lists every command.
